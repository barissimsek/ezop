# Ezop

Open-source tools for AI agent observability.

| Project | Description |
|---|---|
| [platform](platform/README.md) | The Ezop observability platform: dashboard (`ezop-light-ui`), API server (`ezop-platform`), and Python SDK (`ezop-sdk`). Tracks agent registrations, versions, runs, spans, and events. |
| [agentcost](agentcost/README.md) | Agent cost regression CI (`ezop-agentcost` on PyPI). Runs your agent on base and head of a pull request and explains why its cost changed. |
